# Security policy

## Report a vulnerability

Use **Report a vulnerability** in this repository's GitHub Security tab. That route creates a private security advisory for the maintainer.

Do not include exploit details, credentials, personal data, private repository content, or confidential evidence in a public issue. If private vulnerability reporting is unavailable, open a public issue containing no sensitive detail and ask the maintainer to establish a private reporting route.

## What to include privately

- affected plugin version and ChatGPT or Codex surface;
- a concise impact statement;
- reproducible steps using safe test data;
- the smallest relevant files or prompts;
- any containment already applied.

## Scope

Reports may cover packaged skills, build and validation scripts, distribution metadata, privacy or secret leakage, and behavior that contradicts the documented authority boundary. OpenAI-hosted products, GitHub, adopter-owned projects, and unrelated third-party services remain under their respective security processes.

The 5th Ledger is procedural guidance. It does not replace filesystem permissions, repository controls, CI, platform policy, or security review.
