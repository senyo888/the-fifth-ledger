# Support

The 5th Ledger is supported in English on a best-effort basis. There is no service-level agreement or guaranteed response time.

## Ask for help

Use the repository's GitHub issue tracker for installation questions, documentation problems, compatibility reports, and reproducible defects. Before opening an issue:

- remove credentials, personal data, local paths, private repository names, raw agent transcripts, and confidential project evidence;
- describe the ChatGPT or Codex surface, operating system, plugin version, expected behavior, and observed behavior;
- include only the smallest public-safe reproduction needed to understand the problem.

The issue tracker is public. Do not use it for vulnerabilities or sensitive disclosures.

## Security reports

Follow [SECURITY.md](SECURITY.md). Use GitHub's private vulnerability-reporting route when it is available.

## Scope

Before directory publication, support covers this project home's public documentation and candidate feedback only. After a version is actually published, it also covers that published The 5th Ledger plugin. It does not cover adopter-owned repositories, custom project policy, third-party services, OpenAI account access, or actions performed by a user or host agent under separate permissions.
