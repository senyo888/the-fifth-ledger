## Lifecycle truth

An accepted publication direction is not a submitted or published plugin. The required sequence remains:

1. exact candidate preparation and validation;
2. private installation and fresh-context testing;
3. a complete validated OpenAI Platform draft;
4. explicit owner authority to submit for review;
5. OpenAI approval;
6. explicit owner authority to publish;
7. directory publication and post-publication observation.

Until the final publication action has current external evidence, this repository must not claim public Plugins Directory availability.

## Containment

Local candidates can be uninstalled and their temporary marketplace removed. Source changes use additive Git reverts. A draft can be abandoned before submission. Withdrawal, unpublish, and supersession controls remain unavailable evidence until confirmed in the current Platform and are required before the final publication gate.
