# Local private lane

This directory is the project home's ignored private lane. Only this README is tracked.

Suggested local subdirectories:

- `pilots/` — exact adopter evidence and private validation records;
- `research/` — private notes, raw source references, and identity-bearing material;
- `reports/` — setup, validation, and point-in-time status reports.

Everything else under `local/` is ignored. Do not force-add local contents. A file's
location does not prove its privacy, ownership, retention approval, or publication
safety; apply the relevant evidence and privacy decision before storing it here.
